# YOLO Tagger

## Overview

YOLO Tagger is a web application designed for efficient image labeling, built using React and Tailwind CSS. It simplifies the process of preparing datasets for computer vision models, such as YOLO, by enabling users to upload images and assign labels with ease.

## Key Features

- **Image Upload and Visualization**: Quickly upload and preview images for labeling.
- **Manual Labeling**: Define and assign labels to specific regions within images.
- **Export Compatibility**: Export labeled data in formats compatible with YOLO models.
- **Responsive Design**: Enjoy a modern, user-friendly interface powered by Tailwind CSS.

## Getting Started

Follow these steps to set up and run YOLO Tagger locally:

### Prerequisites

Ensure you have the following installed:
- Node.js (v16 or higher recommended)
- npm (Node Package Manager)

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/eltelon/yolo_tagger.git
   cd yolo_tagger
   ```
2. Install the required dependencies:
   ```sh
   npm install
   ```
3. Start the application in development mode:
   ```sh
   npm start
   ```
   The application will be accessible at [http://localhost:3000](http://localhost:3000).

## Scripts

The following npm scripts are available:

- `npm start`: Launches the application in development mode.
- `npm run build`: Creates an optimized production build in the `build` folder.
- `npm test`: Executes the test suite.
- `npm run deploy`: Deploys the application to GitHub Pages.
